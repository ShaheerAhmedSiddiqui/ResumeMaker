# ResumeMaker
  ResumeMaker is a web-based project developed using HTML, CSS, and JavaScript. The complete user interface is designed with HTML and CSS, focusing on a clean and user-friendly layout. All the core functionality and logic of the application are handled through JavaScript.

This project allows users to create professional resumes by entering their personal, educational, and professional details. JavaScript is used to manage user input, handle dynamic content updates, and generate the final resume layout in real time.
